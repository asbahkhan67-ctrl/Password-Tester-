# Password-Tester-

This project is a basic Java application named Password Tester. It is designed to help users check 
the strength of a password using a simple and user-friendly graphical interface (GUI). The 
application is built using Java Swing, which allows the creation of windows, buttons, text fields, 
and labels for a simple 2D interface. 

Technologies used : Java and Swing.

How to run :

Use any Java debugger and run the file.
